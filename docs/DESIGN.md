# Design du projet

Source de vérité visuelle extraite de la maquette Figma officielle `AllSmart - New Interfaces`.

## Polices
- Police principale : **Ubuntu** (texte courant, navigation, boutons, sous-titres et titres structurés)
- Police cursive / titres signatures : **Zeyada** (police cursive Google Fonts, utilisée pour les grands titres d'accent, signatures créatives et surtitres stylisés conformes à Figma, classe CSS `.font-zeyada`)

## Couleurs
- Couleur primaire / accent : **#F5791F** (Orange vif AllSmart)
- Couleur secondaire : **#1A1A1A** (Noir intense)
- Fond clair : **#FFFFFF** | Fond sombre : **#0D0D0D**
- Texte principal : **#1A1A1A** | Texte secondaire : **#555555**
- Succès : **#16A34A** | Erreur : **#DC2626** | Avertissement : **#D97706**

## Règle imposée à tous les agents
L'IA (Marco, Louis) ne doit jamais introduire une nouvelle couleur ou une
nouvelle police en dehors de cette liste sans validation explicite du
porteur du projet.
